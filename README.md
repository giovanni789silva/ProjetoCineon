# 🎬 CINEON+

### Sua próxima experiência de entretenimento começa aqui!

O **CINEON+** é um projeto de desenvolvimento front-end que apresenta uma proposta de plataforma de streaming moderna, intuitiva e visualmente atrativa. A plataforma reúne diferentes categorias de entretenimento em um só lugar, proporcionando uma experiência de navegação simples e agradável.

---

## 🚀 Sobre o projeto

Desenvolvido como um projeto acadêmico, o CINEON+ busca reproduzir a experiência de uma plataforma de streaming, com uma interface moderna, organização de conteúdos e navegação entre diferentes seções.
O projeto conta com páginas dedicadas a filmes, séries, esportes, transmissões ao vivo e muito mais.

## 🎨 Identidade visual

O CINEON+ apresenta uma identidade visual inspirada no universo do entretenimento digital, utilizando uma combinação de tons de azul e roxo para transmitir modernidade.
A interface foi pensada para oferecer uma experiência intuitiva, com elementos visuais que facilitam a navegação para o usuário.

## 🛠️ Tecnologias utilizadas

As tecnologias utilizadas no desenvolvimento do projeto incluem:

- **HTML5** — Estrutura das páginas.
- **CSS3** — Estilização e identidade visual.
- **JavaScript** — Interatividade e funcionalidades da interface.

## 💻 Como executar o projeto

1. Clone o repositório:

```bash
git clone https://github.com/giovanni789silva/ProjetoCineon
```

2. Entre na pasta do projeto:

```bash
cd ProjetoCineon-main
```

3. Abra o arquivo `index.html` no navegador ou utilize a extensão **Live Preview** do Visual Studio Code.

4. Explore as funcionalidades e conheça o CINEON!
